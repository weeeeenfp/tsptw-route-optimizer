# 配送優先權（priority）示範測資

驗證 `or_tools_engine.py` 的優先權偏好確實會改變拜訪順序（搭配 fix:「修正配送優先權完全失效」一同使用）。

兩份 Excel 地點、地址、時間窗（09:00–17:00）完全相同，**只差在優先權欄**，方便直接對照。

| 檔案 | 說明 |
| --- | --- |
| `門檻示範_無優先_送.xlsx` | 對照組，無 `Priority` 欄，純行駛最佳化 |
| `門檻示範_有優先_送.xlsx` | 多一欄 `Priority`，僅 **id8 何劉米粒食事處 = 1（最優先）**，其餘 = 3（預設） |

## 設計重點

何劉米粒食事處（id8）在自然（最短）路線裡剛好排**最後一站**（10:45，遠超過優先 1 的 09:30 目標）。標成優先 1 後，系統會把它**從最後一站拉到第一站**，整條路線幾乎反向——清楚示範「優先權跨過門檻、確實改變順序」。

## 後端實測結果（預設設定）

| | 對照組（無優先） | 優先組（id8=優先1） |
| --- | --- | --- |
| 何劉米粒食事處到達 / 位置 | 10:45 / 第 9 站 | **09:04 / 第 1 站** |
| 路線 | `0→1→2→3→4→5→6→7→9→8→0` | `0→8→9→7→6→5→4→3→2→1→0` |
| 總距離 | 9.84 km | 11.25 km（多繞 1.4 km 換高優先準時） |

## 用法

於系統「訂單上傳」分頁分別上傳兩份檔、送出排程，即可在路線頁看到差異：何劉米粒食事處在優先組排最前、對照組排最後。
